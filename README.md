# کتاب‌نما

تمرین اول درس برنامه‌سازی وب

## درباره پروژه

در این تمرین یک سایت کتاب با استفاده از HTML، CSS و JavaScript طراحی شده است. ظاهر سایت با الهام از طاقچه ساخته شده و امکان مشاهده، جستجو و مدیریت کتاب‌های موردعلاقه را دارد.

## امکانات پروژه

- نمایش ۱۲ کتاب در ۳ دسته‌بندی
- صفحه اصلی شامل بنر، دسته‌بندی‌ها و ردیف‌های کتاب
- امکان جابه‌جایی بین بنرها و کتاب‌ها
- نمایش جزئیات اولیه هر کتاب
- جستجو بر اساس عنوان کتاب و نام نویسنده
- فیلتر کتاب‌ها بر اساس دسته‌بندی
- نمایش فقط کتاب‌های رایگان
- مرتب‌سازی بر اساس قیمت و امتیاز
- امکان استفاده هم‌زمان از جستجو و فیلترها
- نمایش تعداد نتایج و امکان پاک کردن فیلترها
- افزودن و حذف کتاب از علاقه‌مندی‌ها
- ذخیره علاقه‌مندی‌ها با localStorage
- طراحی راست‌به‌چپ و واکنش‌گرا

## ساختار فایل‌ها

- `index.html`: ساختار اصلی سایت
- `css/style.css`: استایل‌های سایت
- `js/books.js`: اطلاعات کتاب‌ها
- `js/state.js`: مدیریت و ذخیره اطلاعات
- `js/app.js`: عملکرد بخش‌های مختلف سایت

## نحوه اجرا

برای اجرای پروژه کافی است فایل `index.html` را در مرورگر باز کنید.

پروژه نیازی به اینترنت، سرور یا نصب پکیج ندارد.

مرورگر آزمایش‌شده: Google Chrome در macOS

## منابع

اطلاعات کتاب‌ها از سایت Project Gutenberg گرفته شده است:

https://www.gutenberg.org

جلدها با SVG ساخته شده‌اند. توضیحات و نمونه متن‌های فارسی برای پروژه نوشته شده‌اند و قیمت‌ها و امتیازها فرضی هستند.

## وضعیت فعلی

تا این مرحله، صفحه اصلی، نمایش کتاب‌ها، جستجو، فیلترها، مرتب‌سازی و علاقه‌مندی‌ها پیاده‌سازی شده‌اند.

بخش‌های خرید و دریافت کتاب، ورود کاربر و مطالعه نمونه کتاب‌ها در مراحل بعد تکمیل می‌شوند.
