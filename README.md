# کتاب‌نما

تمرین اول درس برنامه‌سازی وب

## درباره پروژه

در این تمرین یک سایت کتاب با استفاده از HTML، CSS و JavaScript طراحی شده است. ظاهر سایت با الهام از طاقچه ساخته شده و امکان مشاهده، جستجو، خرید نمایشی و مدیریت کتاب‌ها را دارد.

## امکانات پروژه

- نمایش ۱۲ کتاب در ۳ دسته‌بندی
- صفحه اصلی شامل بنر، دسته‌بندی‌ها و ردیف‌های کتاب
- جابه‌جایی بین بنرها و کتاب‌ها
- جستجو بر اساس عنوان کتاب و نویسنده
- فیلتر بر اساس دسته‌بندی و رایگان بودن
- مرتب‌سازی بر اساس قیمت و امتیاز
- امکان استفاده هم‌زمان از فیلترها
- نمایش جزئیات کتاب‌ها و کتاب‌های مرتبط
- افزودن و حذف کتاب از علاقه‌مندی‌ها
- خرید نمایشی و دریافت کتاب‌های رایگان
- نمایش کتاب‌های دریافت‌شده در کتابخانه
- نمایش نمونه متن بعضی کتاب‌ها
- ورود و خروج نمایشی کاربر
- اعتبارسنجی شماره موبایل با ارقام فارسی و لاتین
- ذخیره جداگانه کتابخانه و علاقه‌مندی‌های هر حساب
- ذخیره اطلاعات با localStorage
- طراحی راست‌به‌چپ و واکنش‌گرا

## ساختار فایل‌ها

- `index.html`: ساختار اصلی سایت
- `css/style.css`: استایل‌های سایت
- `js/books.js`: اطلاعات کتاب‌ها
- `js/state.js`: مدیریت و ذخیره اطلاعات کاربران
- `js/app.js`: عملکرد بخش‌های مختلف سایت

## نحوه اجرا

برای اجرای پروژه کافی است فایل `index.html` را در مرورگر باز کنید.

پروژه به اینترنت، سرور یا نصب پکیج نیاز ندارد.

مرورگر آزمایش‌شده: Google Chrome در macOS

## حساب کاربری و ذخیره اطلاعات

ورود کاربران به‌صورت نمایشی انجام می‌شود و نیازی به رمز عبور ندارد. برای ورود، نام نمایشی و یک شماره موبایل فرضی با فرمت معتبر وارد می‌شود.

هر حساب با استفاده از شناسه‌ای که از شماره فرضی ساخته می‌شود، اطلاعات جداگانه‌ای دارد. کتاب‌های دریافت‌شده و علاقه‌مندی‌های هر حساب در localStorage ذخیره می‌شوند و بعد از خروج و ورود مجدد باقی می‌مانند.

برای ورود دوباره به یک حساب باید از همان شماره فرضی قبلی استفاده شود.

این سیستم فقط برای شبیه‌سازی محلی است و احراز هویت واقعی انجام نمی‌دهد.

## پاک کردن اطلاعات

برای پاک کردن اطلاعات ذخیره‌شده پروژه، دستورهای زیر را در Console مرورگر اجرا کنید:

```javascript
Object.keys(localStorage)
    .filter(key => key.startsWith("ketabnama-"))
    .forEach(key => localStorage.removeItem(key));

location.reload();
```
