# کتاب‌نما

تمرین اول درس برنامه‌سازی وب

## معرفی پروژه

در این تمرین یک سایت کتاب با استفاده از HTML، CSS و JavaScript خام پیاده‌سازی شده است. طراحی سایت با الهام از طاقچه انجام شده و هدف آن آشنایی با طراحی رابط کاربری، کار با DOM، مدیریت اطلاعات و ذخیره وضعیت در مرورگر است.

کاربران می‌توانند کتاب‌ها را مشاهده و جستجو کنند، به علاقه‌مندی‌ها اضافه کنند، خرید یا دریافت نمایشی انجام دهند و نمونه متن بعضی از کتاب‌ها را مطالعه کنند.

## امکانات پروژه

- نمایش ۱۲ کتاب در ۳ دسته‌بندی مختلف
- نمایش تصاویر جلد کتاب‌ها از فایل‌های محلی
- صفحه اصلی شامل بنر، دسته‌بندی‌ها و سه ردیف کتاب
- امکان جابه‌جایی بین بنرها و ردیف‌های کتاب
- بزرگ شدن ملایم کارت‌ها هنگام قرار گرفتن موس روی آن‌ها
- نمایش برچسب رایگان روی کتاب‌های رایگان
- جستجو بر اساس عنوان کتاب و نام نویسنده
- فیلتر بر اساس دسته‌بندی و رایگان بودن کتاب
- مرتب‌سازی کتاب‌ها بر اساس قیمت و امتیاز
- امکان استفاده هم‌زمان از جستجو، فیلتر و مرتب‌سازی
- نمایش تعداد نتایج و پیام مناسب هنگام پیدا نشدن کتاب
- صفحه جزئیات شامل اطلاعات کتاب و سه کتاب مرتبط
- افزودن و حذف کتاب از علاقه‌مندی‌ها
- خرید نمایشی کتاب‌های پولی و دریافت کتاب‌های رایگان
- نمایش کتاب‌های دریافت‌شده و علاقه‌مندی‌ها در کتابخانه
- ورود و خروج نمایشی کاربران
- اعتبارسنجی نام و شماره موبایل با ارقام فارسی و لاتین
- ذخیره جداگانه کتابخانه و علاقه‌مندی‌های حساب‌های مختلف
- نمایش نمونه متن چندبندی برای چهار کتاب
- امکان انتخاب سه اندازه قلم برای مطالعه
- تغییر تم مطالعه بین حالت روشن و تیره
- ذخیره تنظیمات مطالعه برای هر حساب
- طراحی فارسی، راست‌به‌چپ و واکنش‌گرا

## ساختار پروژه

```text
WP-HW1/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   ├── books.js
│   ├── state.js
│   └── app.js
└── assets/
    └── covers/
        └── pictures for books cover
```

توضیح فایل‌ها:

- `index.html`: ساختار اصلی صفحه و بارگذاری فایل‌های CSS و JavaScript
- `css/style.css`: طراحی ظاهری، رنگ‌ها، کارت‌ها و واکنش‌گرایی صفحات
- `js/books.js`: اطلاعات کتاب‌ها، مسیر تصاویر و جلدهای جایگزین SVG
- `js/state.js`: مدیریت اطلاعات حساب‌ها، کتابخانه، علاقه‌مندی‌ها و تنظیمات مطالعه
- `js/app.js`: منطق صفحات، جستجو، فیلترها، رویدادها و تعاملات کاربر
- `assets/covers`: تصاویر جلد کتاب‌ها
- `README.md`: توضیحات پروژه و راهنمای اجرا

## نحوه اجرا

برای اجرای پروژه کافی است فایل `index.html` را در مرورگر باز کنید.

نیازی به نصب پکیج، اجرای سرور یا اتصال به اینترنت وجود ندارد. تمام فایل‌های موردنیاز داخل پروژه قرار گرفته‌اند.

مرورگر استفاده‌شده برای آزمایش: Google Chrome در macOS

## اطلاعات کتاب‌ها

اطلاعات ۱۲ کتاب در فایل `books.js` به‌صورت آرایه‌ای از اشیا نگهداری می‌شود. هر کتاب شناسه یکتا، عنوان، نویسنده، دسته‌بندی، تصویر جلد، توضیحات، قیمت و امتیاز دارد.

چهار کتاب رایگان هستند و برای چهار کتاب نیز نمونه متن چندبندی در نظر گرفته شده است.

تصاویر جلد داخل پوشه `assets/covers` قرار دارند. در صورت بارگذاری نشدن تصویر، یک جلد جایگزین SVG برای کتاب تعریف شده است.

قیمت‌ها و امتیازهای کتاب‌ها فرضی هستند.

## حساب کاربری و ذخیره اطلاعات

ورود کاربران در این پروژه به‌صورت نمایشی انجام می‌شود و نیازی به رمز عبور ندارد.

برای ورود، کاربر نام نمایشی و یک شماره موبایل فرضی با فرمت معتبر وارد می‌کند. شماره باید ۱۱ رقم داشته باشد و با ۰۹ شروع شود.

برای هر حساب، یک شناسه از شماره واردشده ساخته می‌شود و اطلاعات مربوط به کتابخانه، علاقه‌مندی‌ها و تنظیمات مطالعه آن حساب به‌صورت جداگانه در `localStorage` ذخیره می‌شود.

بعد از خروج و ورود مجدد با همان شماره فرضی، اطلاعات قبلی حساب بازیابی می‌شوند.

شماره موبایل به‌صورت مستقیم در اطلاعات ذخیره‌شده قرار نمی‌گیرد. این سیستم صرفاً برای شبیه‌سازی محلی است و امنیت یا احراز هویت واقعی ارائه نمی‌کند.

خرید کتاب‌ها نیز نمایشی است و هیچ پرداخت واقعی انجام نمی‌شود.

## پاک کردن اطلاعات ذخیره‌شده

برای حذف اطلاعات ذخیره‌شده پروژه، می‌توان کد زیر را در Console مرورگر اجرا کرد:

```javascript
Object.keys(localStorage)
    .filter(key => key.startsWith("ketabnama-"))
    .forEach(key => localStorage.removeItem(key));

location.reload();
```

با اجرای این کد، حساب‌های نمایشی، کتابخانه‌ها، علاقه‌مندی‌ها و تنظیمات مطالعه ذخیره‌شده پاک می‌شوند.
