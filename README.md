# کتاب‌نما

تمرین اول درس برنامه‌سازی وب

## معرفی پروژه

در این تمرین یک سایت کتاب با استفاده از HTML، CSS و JavaScript خام پیاده‌سازی شده است. طراحی سایت با الهام از طاقچه انجام شده و کاربران می‌توانند کتاب‌ها را مشاهده و جستجو کنند، به علاقه‌مندی‌ها اضافه کنند و به‌صورت نمایشی خریداری یا دریافت کنند.

## امکانات پروژه

- نمایش ۱۲ کتاب در ۳ دسته‌بندی
- صفحه اصلی شامل بنر، دسته‌بندی‌ها و ردیف‌های کتاب
- جابه‌جایی بین بنرها و ردیف‌های کتاب
- جستجو بر اساس عنوان کتاب و نویسنده
- فیلتر بر اساس دسته‌بندی و رایگان بودن
- مرتب‌سازی بر اساس قیمت و امتیاز
- امکان استفاده هم‌زمان از فیلترها
- نمایش جزئیات کتاب‌ها و کتاب‌های مرتبط
- افزودن و حذف کتاب از علاقه‌مندی‌ها
- خرید نمایشی و دریافت کتاب‌های رایگان
- نمایش کتاب‌های دریافت‌شده و علاقه‌مندی‌ها در کتابخانه
- ورود و خروج نمایشی کاربران
- اعتبارسنجی شماره موبایل با ارقام فارسی و لاتین
- ذخیره جداگانه کتابخانه و علاقه‌مندی‌های هر حساب
- نمایش نمونه متن کتاب‌ها
- تغییر اندازه قلم و تم روشن و تیره هنگام مطالعه
- ذخیره تنظیمات مطالعه برای هر حساب
- طراحی راست‌به‌چپ و واکنش‌گرا

## ساختار فایل‌ها

- `index.html`: ساختار اصلی سایت
- `css/style.css`: استایل‌ها و طراحی صفحات
- `js/books.js`: اطلاعات کتاب‌ها و تصاویر جلد
- `js/state.js`: مدیریت وضعیت و ذخیره اطلاعات کاربران
- `js/app.js`: منطق و عملکرد بخش‌های مختلف سایت
- `README.md`: توضیحات پروژه و راهنمای اجرا

## نحوه اجرا

برای اجرای پروژه کافی است فایل `index.html` را در مرورگر باز کنید.

پروژه به اینترنت، سرور یا نصب پکیج و کتابخانه خارجی نیاز ندارد.

مرورگر استفاده‌شده برای آزمایش: Google Chrome در macOS

## حساب کاربری و ذخیره اطلاعات

ورود کاربران در این پروژه به‌صورت نمایشی انجام می‌شود و نیازی به رمز عبور ندارد. برای ورود، یک نام نمایشی و شماره موبایل فرضی با فرمت معتبر وارد می‌شود.

برای هر حساب یک شناسه جداگانه ساخته می‌شود و اطلاعات کتابخانه، علاقه‌مندی‌ها و تنظیمات مطالعه آن حساب با استفاده از `localStorage` ذخیره می‌شوند.

بعد از خروج و ورود مجدد با همان شماره فرضی، اطلاعات قبلی حساب بازیابی می‌شوند.

شماره موبایل به‌صورت مستقیم ذخیره نمی‌شود و این سیستم فقط برای شبیه‌سازی محلی است و احراز هویت واقعی ندارد.

## پاک کردن اطلاعات ذخیره‌شده

برای پاک کردن اطلاعات پروژه، کد زیر را در Console مرورگر اجرا کنید:

```javascript
Object.keys(localStorage)
    .filter(key => key.startsWith("ketabnama-"))
    .forEach(key => localStorage.removeItem(key));

location.reload();
```

## آزمایش پروژه

بخش‌های مختلف سایت شامل جستجو، فیلترها، مرتب‌سازی، علاقه‌مندی‌ها، خرید نمایشی، ورود و خروج و تنظیمات مطالعه بررسی شده‌اند.

ماندگاری اطلاعات بعد از رفرش صفحه و جدا بودن اطلاعات حساب‌های مختلف نیز آزمایش شده است.

نمایش سایت در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شده است.
